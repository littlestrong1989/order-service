Order Service · 订单管理系统 API

Spring Boot 3 + RBAC 权限 + 乐观锁防超卖 + 事务 + 单元/集成测试 + Docker 化

Swagger UI 健康检查 OpenAPI JSON

项目亮点

🔒 乐观锁防超卖

Product 用 @Version 做乐观锁，下单扣库存并发安全，不会超卖。

🛡️ RBAC 权限

商品读公开、写仅 ROLE_ADMIN；订单需登录，普通用户只能看/操作自己的订单。

🧾 事务一致性

下单「扣库存 + 建订单 + 建明细」在同一事务内；取消订单自动回滚库存。

📸 价格快照

订单项保存下单时的商品名与单价，商品后续改价不影响历史订单。

🧪 10 项测试

单元测试 + 集成测试覆盖核心链路（下单、超卖、权限、取消回滚）。

🐳 Docker 化

提供镜像构建与 MySQL profile，可直接容器化部署。

技术栈

快速开始

# demo profile：H2 内存库，免配置启动
mvn spring-boot:run

# 打开本页
open http://localhost:8080/
# Swagger UI : http://localhost:8080/swagger-ui.html
# 健康检查   : http://localhost:8080/actuator/health

# 演示账号
admin / admin123     → ROLE_ADMIN（可管理商品、可看全部订单）
user  / user123      → ROLE_USER （只能下单并查看自己的订单）

# 跑测试
mvn test

命令行调用示例

# 1) 登录拿 token
curl -s -X POST http://localhost:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"user","password":"***"}'

# 2) 浏览商品（公开，无需 token）
curl -s "http://localhost:8080/api/products?page=1&size=5"

# 3) 下单（需 token）
curl -s -X POST http://localhost:8080/api/orders \
  -H "Authorization: Bearer ***" \
  -H 'Content-Type: application/json' \
  -d '{"items":[{"productId":1,"quantity":2}]}'

方法路径权限说明
POST/api/auth/login公开登录并返回 JWT
GET/api/products公开分页检索商品（keyword / active / sort）

DELETE/api/products/{id}仅 ADMIN下架商品（软删除）

GET/api/orders需登录订单列表（普通用户仅自己；ADMIN 可查全部）
GET/api/orders/{orderNo}需登录订单详情（非本人 403）
POST/api/orders/{id}/cancel需登录取消订单并回滚库存
GET/actuator/health公开健康检查

统一响应体 {"code":0,"message":"ok","data":…}；鉴权头 Authorization: Bearer <token>（有效期 120 分钟）。 下单请求体：{"items":[{"productId":1,"quantity":2}]}（单次最多 50 项）。
